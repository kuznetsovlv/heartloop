# Project glossary

## Users

| Termin   | Description                                                  |
| -------- | ------------------------------------------------------------ |
| **User** | The user is both the recipient (Beneficiary) and the sender of donations (Donor) |

## Fin terms

| Termin          | Description                                                  |
| --------------- | ------------------------------------------------------------ |
| **Donation**    | One time or recurring                                        |
| **Campaign**    | An organized activity to raise funds for a specific purpose  |
| **Fee**         | Service fee for transfers. The fee is charged either to the sender or the recipient (the donor chooses whether to pay it themselves or leave it to the recipient) |
| **Withdraw**    | Withdrawal of funds                                          |
| **Target goal** | Fundraising purpose                                          |
| **Deadline**    | End of fundraising                                           |
| **Amount**      | Amount of funds (transfer or total collected)                |
